# Diagrammes UML - TranscriBITE

Ce dossier contient les diagrammes UML utilisés pour représenter l'architecture et le fonctionnement de TranscriBITE.

## Diagrammes

### Use Case Diagram

`use_case.puml`

Représente les principales fonctionnalités accessibles à l'utilisateur.

### Sequence Diagram

`sequence.puml`

Représente les échanges entre les différents composants lors du traitement d'un fichier.

### Class Diagram

`class_diagram.puml`

Représente les principales classes, modèles et relations du système.

### Component Diagram

`component_diagram.puml`

Représente l'organisation des principaux composants logiciels de TranscriBITE.

### Deployment Diagram

`deployment_diagram.puml`

Représente l'environnement d'exécution et le déploiement des différents composants.

## Technologie

Les diagrammes sont écrits avec PlantUML afin de permettre leur génération à partir des fichiers `.puml`.

## Organisation

Les diagrammes sont conservés dans ce dossier afin de centraliser la documentation UML du projet.

Ils doivent rester cohérents avec l'architecture réelle du projet et être mis à jour lorsque l'architecture évolue.
